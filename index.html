About ForgeDec

                    
ForgeDec is a state-of-the-art byte-level inspector and decompiler designed for web and systems developers. It runs 100% in your browser using structured binary parsers written in JavaScript.

                    
                    
Supported File Formats

                    
    
                        
  • Java Class Files (`.class`): Reads constant pools, parses bytecode instructions, visualizes fields & methods, and reconstructs Java code structures.
    • 
                        
  • WebAssembly (`.wasm`): Parses all binary sections, decodes function signatures and imports/exports, and disassembles instructions to standard WAT representation.
    • 
                        
  • Python Compiled Bytecode (`.pyc`): Supports Python compiler magic headers, walks the marshalled code objects, and lists JVM-like Python instructions.
    • 
                        
  • MetaTrader 4 & 5 (`.ex4`, `.ex5`): Extracts build versions, compiler timestamps, system imports/DLL targets, and scans the binary to decrypt and extract string constant tables.
    • 
                        
  • JavaScript (`.js`): Beautifies minified javascript, expands hex/unicode strings, and reformats packed scripts.
    • 
                    


                    
Interactive Features

                    
    
                        
  • Linked Hex View: View raw binary representation side-by-side with disassembly. Hovering over code components will highlight corresponding byte offsets!
    • 
                        
  • Constant Pool Browser: (Java) Explore references, symbols, types, and strings used in the binary with single-click tracking.
    • 
                        
  • Instant Outline: Rapidly search and jump to classes, methods, imports, and variables within large binaries.
